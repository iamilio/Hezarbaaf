# Muqarnas and karbandi: sources and rules (research log)

Status: reading phase. No code yet. Nothing goes into the plugin until its rule is written here with a source.
"Read" = the full text has been read; "abstract" = only the abstract or a summary; "to get" = not yet seen.

## Karbandi (کاربندی / رسمی‌بندی)

### Rules found so far
| # | Rule | Source | Status |
|---|---|---|---|
| K1 | The base must fit in a circle whose centre lies inside the base. The circle is divided into n equal parts and every corner of the base must fall on a division point. | Amjad Mohammadi, Asefi, Nejad Ebrahimi 2018 | summary |
| K2 | Division points are joined by equal chords. On a rectangle, if the long side spans k divisions, points are joined k by k. Chords outside the base, and those inside the sousani, are erased. | same | summary |
| K3 | Rectangular base: n = 2(a + b − 2) = P − 4, with a and b the side counts and P the perimeter count. n is always even. | same | summary |
| K4 | Two families by how the ribs stand: shagooli (plumb) and sar-seft (out of plumb). | same | summary |
| K5 | Height and elaboration depend on the connection distance; height and shamseh size move in opposite directions. | Amjad Mohammadi, Nejad Ebrahimi, Shahbazi 2019 | abstract |
| K6 | Beyond simple rasmi karbandi there are compound and special kinds, and five non-simple kinds: duplication (parvar), mounted (savar), dual-arch (do-chafdi), extension (gostaresh), endogenous (darun-za). | Mohammadian Mansoor, Faramarzi 2012 | abstract |
| K7 | For a 16-part two-leg karbandi with panj-o-haft ribs, a base angle of 50–53° gives the most even axial forces. | Hayaty, Shahriary, Moradi | abstract |

## Muqarnas (مقرنس)

### Rules found so far
| # | Rule | Source | Status |
|---|---|---|---|
| M1 | A muqarnas is built in tiers of cells; each cell has vertical facets and a roof; the module is the base of the largest facet (the side of the square) and every element is sized from it. | al-Kashi 1427, via Dold-Samplonius 1992 and the Heidelberg project | summary |
| M2 | Four kinds: simple and clay-plastered (flat facets and roofs; clay-plastered may have tiers of unequal height), curved (curved roofs), Shirazi (curved, with more kinds of cell). | same | summary |
| M3 | In plan every element is one of a small set: square, half-square, rhombus, half-rhombus, almond, small biped (almond + small biped = rhombus), jug (quarter octagon), large biped (jug + large biped = square). | Harmsen 2006; Heidelberg project | summary |
| M4 | An element is either a cell or an intermediate element that joins neighbouring cells; the same plan shape can be either, so a plan alone does not fix the 3D form. | Heidelberg project | summary |
| M5 | A plan becomes 3D by reading it as a graph with a direction on each edge; one plan can give several valid vaults, and the proportions of the niche or dome limit the number of tiers. | Harmsen 2006 | abstract |
| M6 | Plans fall into the square-lattice kind (squares and 45° rhombi), the pole-table kind (radial), and others. In the 45° system every angle is a multiple of 22.5°. | Takahashi; Hietbrink 2021 | summary |
| M7 | al-Kashi describes the elements, not how to compose them. Composition has to be learned from surviving plans. | Özdural 1990, via Agirbas & Yildiz | summary |

## Open questions
1. Karbandi in 3D: how the rib curve, the heights of the crossing points and the shamseh level are fixed (Sha'rbaf; Amjad Mohammadi 2019).
2. Karbandi names: the n-and-legs naming (e.g. "16 two-leg") against K2's k-by-k rule.
3. Muqarnas composition: which elements may sit next to and above which (Harmsen ch. 2–3).
4. Muqarnas profile: al-Kashi's "method of the masons" for the cell curve (Dold-Samplonius 1992).
5. Brick: which historical muqarnas are structural brick corbels and which are plaster or tile shells hung from a vault. Decides what Hezarbaaf may honestly call buildable.
